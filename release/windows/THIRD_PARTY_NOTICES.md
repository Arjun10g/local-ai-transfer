# Third-party notices for the checked-in Windows source skeleton

This source skeleton does not bundle `runtime/node.exe`, a native engine, or
the Node.js and llama.cpp license files. `node-provenance.json` records an
intended future input only; it is not evidence that Node.js is present.

Portable-package construction is currently disabled. A future accepted builder
must generate notices and include complete license texts from the exact bytes it
actually packages. Model weights are external and are not redistributed here.
