## Assumptions

- The target build may be performed remotely; local macOS tool availability is not a release claim.
- A standard C++17 compiler and CMake are sufficient for the dependency-free fixture binary.
- Fixture mode is explicitly non-production and uses no model, network client, or target-side download.
- Runtime authentication uses a caller-supplied bearer token; health remains observable while readiness and other operational endpoints require auth.
